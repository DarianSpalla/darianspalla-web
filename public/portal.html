Configuración de sincronización

Para que los usuarios registrados desde sus propios dispositivos aparezcan en tu panel, necesitás configurar una base de datos en la nube. Usamos JSONBin.io — es gratis y no requiere servidor.

Pasos para configurar:
  1. Entrá a cloudflare.com con tu cuenta
  2. Workers & Pages → Create → Create Worker → nombre: darian-coaching-db
  3. Pegá el código del Worker y Deploy
  4. KV → Create namespace → nombre: COACHING_DB
  5. En el Worker → Settings → Variables → KV Bindings → agregar DB → COACHING_DB
  6. Copiá la URL del Worker (ej: https://darian-coaching-db.xxx.workers.dev) y pegala abajo
